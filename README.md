# Axis для Android

Axis — Android-ассистент с текстовым чатом, диктовкой и озвучиванием. Первая сборка для разработки. Минимальная версия — Android 10 (API 29).

## Что доступно

- До 12 профилей OpenAI-совместимых провайдеров. У каждого свой базовый HTTPS-адрес, ID модели, ключ и история.
- Проверка подключения реальным запросом к модели. В чате можно остановить ожидание ответа или очистить локальную историю.
- Диктовка через системное приложение распознавания речи. Распознанный текст появляется в поле ввода, где его можно отредактировать. Русское озвучивание работает при наличии соответствующего голоса Android.

Управление приложениями и работа с файлами находятся в дорожной карте. В этой сборке провайдер возвращает обычный текст, а пользователь запускает диктовку вручную.

## Подключение модели

1. Откройте **Модели → Добавить профиль**.
2. Укажите имя, базовый адрес API (например, `https://api.openai.com/v1`), точный ID модели у провайдера и ваш ключ.
3. Сохраните профиль. Нажмите **Проверить соединение**, затем выберите его и вернитесь в чат.

Провайдер должен поддерживать `POST /chat/completions` с авторизацией Bearer и текстовым ответом. Axis отправляет выбранному провайдеру текст запроса и недавнюю историю этого профиля. Запросы, включая проверку соединения, могут расходовать лимит или баланс. Системные голосовые службы работают по своим настройкам и могут использовать сеть.

Ключи шифруются через Android Keystore. Данные находятся в каталоге приложения, исключённом из резервного копирования. Смена адреса профиля требует нового ключа и очищает локальный чат этого профиля. Очистка чата и удаление профиля действуют на данные Axis на устройстве.

## Сборка и установка

Требуются JDK 17 или 21, Android SDK Platform 35, Build Tools 35.0.0 и принятые лицензии SDK. Укажите путь к SDK через `ANDROID_HOME` или откройте проект в Android Studio.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

В Windows используйте `gradlew.bat`. В GitHub Actions APK доступен в артефакте `axis-debug` успешного запуска **Android CI**. Это debug-сборка для тестирования.
